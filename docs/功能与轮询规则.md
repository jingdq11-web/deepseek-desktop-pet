## 一、三个定时器（一切从这里开始）

整个桌宠只有**三个**节奏来源。看懂这三个，后面所有功能都是它们的派生。

### 1️⃣ 主循环 `CompanionTick` —— 40 毫秒（每秒 25 次）

`CompanionWindow.cs:494`　`companionTimer.Interval = 40ms`

| 每帧做的事 | 说明 |
|---|---|
| 记下前台窗口句柄 | 存 `lastExternalForeground`，给「看屏幕汇报」用（因为右键菜单弹出时前台会变成自己） |
| 算帧间隔 `dt` | 上限 0.15 秒，防止卡顿后跳帧 |
| 已关闭 / 正在播退出动画 | 直接 `return`，后面全不跑 |
| `CompanionExtrasTick()` | 内部自带 1 秒闸（见下） |
| `UpdateVitalsHud()` | 每帧推进右上角仪表动画：每帧向目标值靠 **12%**，<25 脉动，刚变化时闪 1.6 秒 |
| `brain.RefreshWeather()` | 只在 `PublicInfo` 开启时调，内部自己节流（45 分钟） |
| 电源策略 | 拔电且设了「暂停模型」→ 卸载模型、清气泡 |
| 模型预热 | 满足条件时**每 2 分钟**一次 `WarmUp()` |
| 全屏检测 | 全屏应用在前台 → 隐藏；退出全屏 → 回来 |
| 气泡超时 | `now > bubbleUntil` → 收起 |
| 说话判定 | 见「二、主动说话」 |

### 2️⃣ 日常总闸 `CompanionExtrasTick` —— 1 秒一次

`CompanionDaily.cs:30`　所有日常功能都挂在这里，**不再各自加定时器**。

```
每秒一次：
  VitalsTick()        数值衰减 + 主动社交（讨吃 / 犯困 / 黏人）
  PomodoroTick()      番茄钟到点
  SitTick()           久坐提醒
  BirthdayTick()      生日
  HousekeepingTick()  一天一次的目录保洁
```

内部用 `extrasNextTick` 做闸门，所以即使主循环 40ms 跑一次，这些逻辑仍是严格的 1 秒一次。
异常会被捕获并写 `companion-extras-errors.log`（只写一次，不刷屏）。

### 3️⃣ 动画边界 `AnimationBoundary` —— 事件驱动（不是定时器）

`CompanionAnimations.cs:118`　**每个动作播完**时回调一次，按下面顺序判断，命中就 `return`：

| 顺序 | 条件 | 结果 |
|---|---|---|
| 1 | 提线木偶模式 | 待机 |
| 2 | 退出中 / 拖拽中 / 被隐藏 / 全屏 / 设置窗口开着 | 待机 |
| 3 | 23:00 且今天还没刷过牙 | 播「晨间刷牙」（一天一次） |
| 4 | `TryVitalsAnimation()` 命中 | 播低数值对应动作（见下） |
| 5 | `nextAction` 到点（默认 **40 秒**） | 自播一个动作 |
| 6 | 都不满足 | 待机（`Idle` 池） |

`TryVitalsAnimation()` 的三条概率：

- 精力 < 18 → **55%** 概率播「打瞌睡 / 小憩 / 沉眠 / 哈欠 / 发呆」
- 饱食 < 22 → **55%** 概率播一个吃饭动作
- 好感 > 80 → **20%** 概率播「撒娇 / 开心 / 跃动 / 哼歌 / 伸懒腰」

## 二、主动说话：什么时候开口

`CompanionWindow.cs:680`　判定链：

```
PuppetActive / 没到 nextSpeech / 设置窗口开着 / 模型没就绪  → 不说
键盘鼠标空闲 < 8 秒  → 30 秒后再看（你刚在打字，别打断）
键盘鼠标空闲 > 600 秒 → 30 秒后再看（人不在，说了也没人看）
否则 → 让模型生成一句
```

**间隔怎么算**（`CompanionPreferences.NextSpeechDelay`）：

```
基准 = 在档位区间里随机取值
      档位默认 10 → 区间 10~16 分钟（可选 2/3/5/10/15/20 六档）
系数 = 1.55 - 好感 × 0.010          → 好感 100 → 0.55 倍，好感 0 → 1.55 倍
       精力 < 25 再 ×1.7
       精力 < 45 再 ×1.25
       精力 > 75 再 ×0.9
最终 = clamp(基准 × 系数, 1 分钟, 90 分钟)
```

举例：好感 55、精力 82 → 系数 0.90，实际间隔约 **9~14 分钟**。
好感 96、精力 90 → 系数 0.59，实际间隔约 **6~9 分钟**。

## 四、106 个动作怎么自己播（本次改动）

### 动作池分布（`animations.json`）

| Pool | 数量 | 原版行为 | 现在的自播行为 |
|---|---|---|---|
| `Event` | 91 | ✅ 40 秒自播 | ✅ 权重 ×1.0 |
| `Idle` | 3 | ✅ 兜底待机 | ✅ 权重 ×0.6 |
| `Click` | 5 | ❌ 只在你点她时 | ✅ **权重 ×0.6（会自己播了）** |
| `Drag` | 1 | ❌ 只在拖拽时 | ❌ 仍然只在拖拽时（拖拽必须有人） |
| `Greeting` | 1 | ❌ 只在启动时 | ✅ 权重 ×0.3 |
| `Daily` | 1 | ❌ 只在 23:00 | ✅ 权重 ×0.3 |
| `Disabled` | 4 | ❌ 永不播 | ❌ 仍然不播（作者标记为停用） |

### 为什么以前「感觉只有那几个」

除了池子限制，`animations.json` 里还有四类约束会把权重直接压成 **0**：

| 约束 | 字段 | 效果 |
|---|---|---|
| 只在夜里 | `NightOnly` | 白天权重 0 |
| 只在某个季节 | `SeasonOnly` | 其他季节权重 0 |
| 只在节日前后 | `Festival` + `RadiusDays` | 距离节日太远权重 0 |
| 只在整点前后 | `MoveKind` + `HourParity` | 分钟不在 0~5 / 55~60 或小时奇偶不对 → 权重 0 |

所以中秋赏月、堆雪人、放烟花这类动作，一年里绝大多数时间都**不可能**出现。

### 现在的算法

```
候选池 = 所有动作，排除 Pool = Disabled 和 Drag   → 101 个
基础权重 = 官方 Weight() 算出来的值（0 ~ 1000）
           如果算出来 ≤ 0（被上面的约束压掉了）→ 给保底值 25
压缩     = 25 或 基础权重 取 0.35 次方 × 15
           作者的权重跨度是 50 倍（20 → 1000），直接用会让低权重动作几乎永远抽不到；
           开方后跨度收敛到 4~5 倍，常见动作还是更常见，但没有动作会被饿死
再乘池子系数：Click 0.60 / Idle 0.60 / Greeting·Daily 0.30 / 其余 1.0
再乘反重复系数：上一个播的 0.05 / 最近 8 个里出现过的 0.30
按权重轮盘随机
```

实测（2000 次采样的真实分布）：

```
覆盖 101 / 101 个动作，一个都没漏
Click 池 5 个动作各自命中 5 ~ 11 次
最少 4 次、中位 18 次、最多 54 次（吃白饭）
```

换算成时间（默认 40 秒自播一次）：中位动作约 **75 分钟**轮到一次，最常见的约 25 分钟一次，
最稀有的（请安 / 刷牙 / 少数节日动作）约 5 小时一次——它们本来就有专门的触发时机。

开关：设置 → 鱼鱼的日常 → 「所有动作都会自己播（不只是点了才播）」，默认开。
关掉就完全退回原版行为（只有 `Event` 池自播）。

## 五、三个数值的规则（含本次投喂改动）

### 投喂

| 项目 | 改前 | 改后 |
|---|---|---|
| 每次投喂加饱食 | +30（两下就满） | **+2.5（50→100 正好 20 次）** |
| 饱食自然衰减 | −4 / 小时 | **−1.5 / 小时** |
| 讨吃阈值 | 饱食 < 30 | **饱食 < 50**（因为涨得慢了，卡 30 她一天都不开口） |

> 为什么衰减也跟着降：投喂一次只加 2.5，如果衰减还是 4/小时，喂一次连 40 分钟都撑不住，
> 永远补不回来。现在 1.5/小时 = 一天不管掉 36 点，大约 14 次投喂能补回来。

### 完整数值表

| 事件 | 变化 |
|---|---|
| 喂她一次 | 饱食 **+2.5**、好感 **+5**、精力 +2 |
| 点她一下（摸头） | 好感 +0.5 |
| 时间流逝 | 饱食 −1.5/时；醒着精力 −5/时；23:00~8:00 精力 +8/时 |
| 长期不管（饱食 <20 **或** 精力 <20） | 好感 −1.2/时；否则只 −0.25/时 |
| 离线补算 | 最多 12 小时，隔三天回来不会发现她「饿死了」 |

### 好感度从哪来（本次扩充）

原来只有「摸头」和「喂食」两个来源，太少了。现在她做的每件事都算数：

| 来源 | 加多少 | 递减 / 冷却 | 说明 |
|---|---|---|---|
| 点她一下（摸头） | +0.5 | 无 | 单击本体 |
| 右键点一个动作 | **+0.5** | 同一个动作 10 分钟内重复只 **+0.1** | 106 个动作，换着点才有全额 |
| 喂她吃一次 | **+5** | 10 分钟内再喂只 **+1** | 既是喂饱也是亲近，最值钱的一档 |
| 从「吃点什么」点某道菜 | **+5** | 同上（和喂食共用一个冷却） | 点菜 = 真的喂到了 |
| 双击找她聊天 | **+1** | 5 分钟最多一次 | 打开聊天输入框 |
| 每发一条消息 | **+0.6** | 30 秒最多一次 | 连发不重复计数 |

> 递减不是为了小气：不这么写的话按住一个动作连点就能把好感刷满，这个数就没意义了。
> 现在想涨好感得**换着动作玩 + 偶尔喂一顿 + 找她说话**，正好也是"陪伴"该有的样子。

实测（基线好感 30）：
```
点 哈欠连天 +0.5 → 再点一次 +0.1 → 点 东张西望 +0.5 → 点 放风筝 +0.5
点菜吃早餐 +5 → 再点同一道 +1 → 喂食 +1
双击开聊 +1 → 5 分钟内再开 0 → 发消息 +0.6 → 30 秒内再发 0
合计 +10.20，与设计值完全一致
```

### 数值怎么影响行为

| 数值 | 行为 |
|---|---|
| 好感 ≥ 85 | 说话间隔 ×0.55；语气黏人撒娇；40 分钟一次概率主动贴贴 |
| 好感 60~85 | 间隔 ×0.90，自然亲近 |
| 好感 35~60 | 正常，友好但克制 |
| 好感 < 15 | 间隔 ×1.40，语气生分 |
| 饱食 < 50 | 主动讨吃的（45 分钟一次；<25 时 20 分钟一次） |
| 精力 < 22 | 白天念叨「眼睛睁不开了」，夜里安静睡；说话间隔 ×1.7 |
| 精力 > 75 | 说话间隔 ×0.90 |

数值落盘：`preferences.json` 的 `Affection` / `Satiety` / `Energy` / `VitalsStamp`，**每 2 分钟写一次**。

## 八、调试命令（测试模式）

在运行目录放一个空的 `test-mode.flag`，或启动时加 `--test-mode`，就会出现：

- `test-status.json`：每秒刷新一次，含 `action` / `animationPhase` / `affection` / `satiety` / `energy` / `bubble` / `bubbleVisible` / `pomodoroRunning` / `foregroundProcess` / `isCoding` 等
- `test-command.txt`：往里面写一行命令，桌宠读走并删掉

| 命令 | 作用 |
|---|---|
| `feed` | 投喂一次 |
| `pomodoro` / `pomodoro-stop` | 番茄钟开 / 关 |
| `report-screen` | 看屏幕汇报 |
| `vitals` | 饱食 / 精力设成 10 |
| `affection-low` / `affection-high` | 好感设成 8 / 96 |
| `aff-chat-open` / `aff-chat-msg` | 触发「双击开聊」/「发消息」的好感（含冷却判定） |
| `vitals-reset` | 恢复成 好感 55 / 饱食 72 / 精力 82 |
| `action:<动作名>` | 立刻播指定动作 |
| `menu:<动作名>` | 走「右键点菜单」那条路播（点「吃点什么」里的会同时喂到她） |
| `auto-sample` | 把自播的随机分布跑 2000 次，写 `auto-sample.json`，用来验证权重 |
| `event:<动作名>` | 按「事件」方式播（带移动） |
| `hide` / `restore` / `exit` | 隐藏 / 恢复 / 退出 |
| `settings` / `close-settings` | 开关设置窗口 |
| `clip-on` / `clip-off` | 剪贴板联动开关 |

**正常使用时记得删掉 `test-mode.flag`**，否则每秒都在写 `test-status.json`（还包含前台窗口信息）。

## 九、一句话总结

> 主循环 40ms 管画面和仪表，日常总闸 1 秒管数值和提醒，动画边界在每次动作播完后决定下一个播什么。
> 40 秒自播一个动作，6~14 分钟说一句话，饿了/困了/太亲了会插队开口。
